# 0.1 实现与验证记录

日期：2026-10-10。本次实现基于 docs/architecture.md 的微软拼音外挂路线。当前为实验开发版，源码已提交公开仓库；远程验证由 GitHub Actions 执行。

## 已实现

- 独立 MTA/UIA 候选读取进程、受保护微软宿主范围、只读 WinEvent、64 KiB 有界 IPC、当前用户与连接进程校验、看门狗和重启冷却。
- WPF 中文主设置、托盘、关闭后台、登录启动、暂停/词典模式、独立不激活点击穿透翻译窗。
- 多来源/语言列、同语言词典兜底、颜色、列顺序与提示词覆盖；来源扩展通过配置和 ITranslationProvider。
- 有界内存 LRU、快照/配置失效、单槽与公平语言顺序、总期限和 SSE 无进展期限。
- SQLite TSV 导入，词条与许可/出处/版本/hash 共包原子替换；15 条原创中英演示数据。
- llama.cpp 托管/外部本机 HTTP、HTTPS 在线兼容适配器；在线省略 enabled 时保持关闭；模型实际模板分词预算与 GGUF Q8_0 校验。
- MIT、第三方许可文本、贡献/安全指南、issue/PR 模板、Linux 测试和 Windows 打包 CI。

## 自动验证

28 项测试全部通过，包括一次独立审查后的回归测试：

| 审查问题 | 回归与修复 |
| --- | --- |
| 总期限覆盖已完成译文 | 只让未完成单元格超时，保留 Ready |
| 手动提示词测试绕过单槽 | 与正常请求共用槽位，等待真实取消计算结束；重复测试串行 |
| 模型 Dispose 与加载并发 | 单一进程所有权锁，取消加载，设置重建等待异步清理 |
| 在线源隐式启用 | 缺省 OnlineModel.enabled 为 false |
| Reader 正常 EOF 留下旧窗口 | 连接结束无条件发送 Hidden |
| 已退出模型永远 Ready | 检查实际进程存活，允许后续重新加载 |

Windows 目标完整 solution 构建通过（0 warnings / 0 errors）；Publish.ps1 在 Linux PowerShell 中交叉发布主程序与 Reader 的 win-x64 自包含包。该证据只证明源码/打包可构建。

尚未运行 Windows 交互、真实微软候选、真实 LMT / CUDA 或模型转换脚本；质量/延迟/显存不作实测结论。详见 windows-validation.md。
